C# Logik-Rätsel & Array-Operationen

Post- vs. Prä-Dekrement

int a = 24;
int b = 33;
// b-- (Post): Wert bleibt 33 für Rechnung
// --a (Prä) : Wert wird sofort 23
int calc = b-- % --a; // 33 % 23 = 10

Trick: Array umkehren mit count++

static int[] Invert(int[] list)
{
    int[] temp = new int[list.Length];
    int count = 0;
    // Schleife läuft rückwärts
    for(int c = list.Length - 1; c >= 0; c--)
    {
        temp[count++] = list[c];
    }
    return temp;
}

Python Syntax & Logik-Fallen

  • range(10, 0): Gibt nichts aus! Rückwärts: range(10, 0, -1)
  • Vergleiche in if: Zwingend == nutzen, nicht =.
  • String + Zahl: Immer casten: "Alter: " + str(23)

Modulo (%) vs. Division (//)

44 // 150 ergibt 0 (Passt 0 mal rein).
44 % 150 ergibt 44 (Der Rest).

📚 Cheat-Sheet: Die wichtigsten Funktionen (Was macht was?)

Hier findest du die absoluten Standard-Befehle, die in fast jeder C#- und Python-Prüfung vorkommen, kurz und knapp erklärt.

Listen & Arrays (C#)

  • .Add(wert) – Hängt ein neues Element ganz ans Ende einer Liste.
  • .Insert(index, wert) – Quetscht ein Element an einer bestimmten Position (Index) rein. Alles andere rutscht eins nach hinten.
  • .Remove(wert) – Sucht den Wert und löscht ihn aus der Liste.
  • .Contains(wert) – Die Suchmaschine: Prüft, ob ein Wert in der Liste/Array existiert. Gibt true oder false zurück.
  • .Clear() – Der Reset-Knopf. Löscht alles aus einer Liste (oder auch den Text aus einer TextBox).

Strings & Umwandlung (C#)

  • Convert.ToInt32(text) – Macht aus einem Text (z.B. aus einer TextBox) eine ganze Zahl (Integer), damit du damit rechnen kannst.
  • .ToString() – Der Rückweg: Wandelt eine Zahl oder ein Objekt wieder in Text um (z.B. um es in einer GUI anzuzeigen).
  • .Trim() – Der Putzteufel: Schneidet versehentliche Leerzeichen am Anfang und Ende eines Textes gnadenlos ab.
  • .ToLower() / .ToUpper() – Wandelt den gesamten Text in Klein- oder Großbuchstaben um. (Perfekt für Suchfunktionen, um Groß-/Kleinschreibung zu ignorieren).

Python (Micro:bit) Äquivalente

  • len(liste) – Das C#-Gegenstück zu .Count. Gibt die Anzahl der Elemente in einer Liste (oder die Länge eines Textes) zurück.
  • liste.append(wert) – Das exakte C#-Gegenstück zu .Add(). Hängt Daten an eine Liste an.
  • int(text) / str(zahl) – Das Casting in Python (entspricht Convert.ToInt32 und .ToString()).
  • range(start, ende) – Erzeugt eine Zahlenfolge für Schleifen. Falle: Die End-Zahl wird beim Zählen nicht mehr mit eingeschlossen!

Variablen-Tracking (Referenzen & In-Place)

Grundaufgabe: Führe das Skript gedanklich aus und notiere den Zustand der Variablen nach jedem Methoden-Aufruf.

Der Ausgangscode

from microbit import *

def verschiebe(liste, wert):
    neue_liste = []
    for zahl in liste:
        neue_liste.append(zahl + wert)
    return neue_liste

def begrenze(liste, max_wert):
    for i in range(len(liste)):
        if liste[i] > max_wert:
            liste[i] = max_wert
    return liste # Ändert die Original-Liste!

def mache_symbole(liste, grenze):
    sym_liste = []
    for zahl in liste:
        if zahl >= grenze:
            sym_liste.append(Image.HAPPY)
        else:
            sym_liste.append(Image.SAD)
    return sym_liste

# --- Hauptprogramm ---
start = [1, 3, 5]
werte_a = verschiebe(start, 2)
werte_b = begrenze(werte_a, 6)
symbole = mache_symbole(werte_b, 5)
start.append(len(symbole))

Die Lösungstabelle

Nach Zeile... start werte_a werte_b
werte_a = verschiebe(...) [1, 3, 5] [3, 5, 7] n/a
werte_b = begrenze(...) [1, 3, 5] [3, 5, 6] [3, 5, 6]
start.append(...) [1, 3, 5, 3] [3, 5, 6] [3, 5, 6]

Die Falle im Code:

Weil begrenze() die Werte direkt über den Index (liste[i]) anpasst und kein neues leeres Array erstellt, verweist werte_b auf denselben Speicherplatz wie werte_a. Änderst du das eine, ändert sich auch das andere!

⚠️ C# Datentypen, Casten & Überläufe (Cutting)

Die Grenzen kennen!

  • byte (8-Bit ohne Minus): 0 bis 255
  • sbyte (8-Bit MIT Minus): -128 bis 127
  • ushort (16-Bit ohne Minus): 0 bis 65.535

Prüfungsfalle "Abstellen" (checked):
C# ignoriert Überläufe standardmäßig leise. Mit checked { ... } zwingst du das Programm, sofort abzustürzen (Exception werfen), wenn ein Limit gesprengt wird!

"Cutting" (Der Überlauf)

Wenn der Wert zu groß ist, fängt er wie ein Kilometerzähler wieder von vorne (oder im tiefsten Minus) an!

int riesig = 256;
byte b = (byte)riesig; 
// b ist 0! (255 war das Limit, 256 springt auf 0)

int zahl = 128;
sbyte sb = (sbyte)zahl; 
// sb ist -128! (127 war Limit, springt ins Minus)

🖥️ GUI Drag & Drop Logik (Point X, Y)

Wenn du Codefenster per Drag-and-Drop anordnen musst, schau nur auf die Zeile Location = new Point(X, Y);

  • X (Erste Zahl): Abstand vom linken Rand (Je größer, desto weiter rechts).
  • Y (Zweite Zahl): Abstand vom oberen Rand (Je größer, desto weiter UNTEN!).
// Steht GANZ OBEN, da Y = 20
TextBox txt = new TextBox();
txt.Location = new Point(50, 20); 

// Steht UNTER der TextBox, da Y = 60
Button btn = new Button();
btn.Location = new Point(50, 60);

🪟 Komplettbeispiel: Strukturierte WinForms App (Personenverwaltung)

Die perfekte Architektur für Prüfungsaufgaben. Der Code ist aufgeteilt in Einlesen (Get), Prüfen (Validate), Speichern (Save) und Ausgeben (Show). 

using System;
using System.Collections.Generic;
using System.Windows.Forms;

namespace Unterricht_01
{
    public partial class Form1 : Form
    {
        // Dies ist die Datenstruktur, in welcher die einzelnen Datensätze abgelegt werden.
        // Die Liste verwaltet einzelne String-Arrays, wobei ein String-Array immer einer Person entspricht.
        private List<string[]> people = new List<string[]>();
        
        public Form1()
        {
            InitializeComponent();
        }

        private void BtnSpeichern_Click(object sender, EventArgs e)
        {
            // Beschaffen der Formulardaten
            string[] formValues = GetFormData();

            // Formulardaten korrektausgefüllt?
            if (ValidateFormData(formValues))
            {
                // Hat das Speichern des Datensatzes in die Liste people geklappt?
                if (SaveFormData(formValues))
                {
                    // Löschen aller Eingabefelder
                    ClearInputFields();

                    // Hat es überhaupt Datensätze anzuzeigen?
                    if (!ShowDataAsText())

                        // Wenn nicht, entsprechende Fehlermeldung ausgeben.
                        UserInformationBox(0);
                }
                else
                {
                    // Wenn Speichern nicht geklappt hat, dann entsprechene Fehlermeldung anzeigen
                    // HINWEIS: Hier auf 2 korrigiert, da das Array nur Index 0, 1 und 2 hat!
                    UserInformationBox(2);
                }
            }
            else
            {
                // Wenn Formularfelder nicht korrekt ausgefüllt wurden, entsprechende
                // Fehlermeldung anzeigen
                UserInformationBox(1);
            }
        }

        /**
         * Setzt alle Eingabefelder wieder auf
         * Default zurück
         */
        private void ClearInputFields()
        {
            TxtbVorname.Clear();
            TxtbNachname.Clear();
            NumAlter.ResetText();
            RadMaennlich.Checked = false;
            RadWeiblich.Checked = false;
            RadDivers.Checked = false;
            TxtbBemerkungen.Clear();
        }

        /**
         * Gibt abhängig von errorCode die entsprechende Fehlermeldung aus
         */
        private void UserInformationBox(int errorCode)
        {
            // Liste mit Fehlermeldungen. Der errorCode entspricht dem Index im Array
            string[] messages = new string[] {
                "Keine Datensätze anzuzeigen",
                "Bitte alle Eingabefelder korrekt ausfüllen!",
                "Das Speichern des Datensatzes hat nicht funktioniert",
            };

            MessageBox.Show(messages[errorCode]);
        }

        /**
         * Falls Daten in Liste vorhanden, werden diese angezeigt
         */
        private bool ShowDataAsText()
        {
            if (people.Count > 0)
            {
                string output = "";
                // Diese Schleife läuft durch die Liste
                foreach (string[] record in people)
                {
                    // Diese Schleife läuft durch einen einzelnen Datensatz (Array)
                    foreach (string value in record)
                    {
                        // Hier werden die Werte des Datensatzes in einen String
                        // gespeichert.
                        output += value + " ";
                    }
                    // Ausgabe erhält am Ende eines Datensatzes noch einen Zeilenumbruch
                    output += "\r\n";
                }
                // Ausgabe-Textbox wird gelöscht
                TxtbPersonenListe.Clear();
                // Ausgabe-Textbox wird mit neuer Ausgabe beschrieben
                TxtbPersonenListe.Text = output;
                return true;

            }
            return false;
        }

        /**
         * Prüft. ob die Formulardaten korrekt eingegen wurden
         */
        private bool ValidateFormData(string[] formValues)
        {
            if (formValues[0].Length <= 0 || formValues[1].Length <= 0 || formValues[3].Length <= 0)
            {
                return false;
            }
            return true;
        }

        /**
         * Speichert Datensatz in der Liste und prüft, ob dies funktioniert hat
         */
        private bool SaveFormData(string[] formValues)
        {
            // Aktuelle Grösse vor dem Hinzufügen
            int currentSize = people.Count;
            // Hinzufügen des neuen Datensatzes
            people.Add(formValues);
            // Neue Grösse nach dem Hinzufügen
            int newSize = people.Count;
            // Ist neue Grösse grösser als alte Grösse?
            if (newSize > currentSize)
                return true;

            return false;
        }

        /**
         * Liest alle Formulardaten ein und gibt einen vollständigen
         * Datensatz als String-Array zurück
         */
        private string[] GetFormData()
        {
            // Eingabefelder einlesen
            string firstname = TxtbVorname.Text;
            string lastname = TxtbNachname.Text;
            string age = Convert.ToString(NumAlter.Value);
            
            string gender = "";
            if (RadMaennlich.Checked)
            {
                gender = "Männlich";
            }
            else if (RadWeiblich.Checked)
            {
                gender = "Weiblich";
            }
            else if (RadDivers.Checked)
            {
                gender = "Divers";
            }

            string comment = TxtbBemerkungen.Text;

            // Hier wird der Datensatz in Form eines String-Arrays zusammengesetzt
            string[] record = new string[] { firstname, lastname, age, gender, comment };
            return record;
        }
    }
}

Block 5: Methoden & Überladung (C#)

void vs. Datentyp (return)

  • void: Führt nur Code aus (kein return nötig).
  • Datentyp (int): Die Methode MUSS einen Wert per return zurückgeben.
public int Addiere(int a, int b)
{
    return a + b;
}

Methoden-Überladung (Overloading)

Methoden dürfen den exakt gleichen Namen haben, solange sich ihre Parameter unterscheiden!

// Version 1: Nimmt nur den Namen
public void AddFriend(string name) { ... }

// Version 2: Nimmt Namen UND Position
public void AddFriend(string name, int position) { ... }

Block 7: Arrays vs. Listen (C#)

Array (Fixe Größe)

Einmal definiert, ändert sich die Größe nie wieder.

int[] zahlen = new int[3]; 
zahlen[0] = 5;

Liste (Flexible Größe)

Wächst dynamisch mit.

List<string> namen = new List<string>();
namen.Add("Max"); // Klatscht Max ganz ans Ende
namen.Insert(0, "Anna"); // Zwingt Anna an Index 0

🚨 Prüfungs-Falle: Count vs. Length

Array-Größe = array.Length
Listen-Größe = liste.Count
Tipp: Mische das auf keinen Fall in der Prüfung!

Algorithmus: Bubble Sort (Smart)

zahlen = [9, 3, -1, 12, 7, 4, 8, 5]
for durchlauf in range(len(zahlen)):
    getauscht = False
    for i in range(len(zahlen) - 1 - durchlauf):
        if zahlen[i] > zahlen[i+1]:
            zahlen[i], zahlen[i+1] = zahlen[i+1], zahlen[i]
            getauscht = True
    if not getauscht:
        break

Kryptographie: Caesar-Chiffre (Robust)

def caesar_encrypt(text, shift):
    result = ""
    for char in text:
        if char.isalpha():
            ascii_base = ord('A') if char.isupper() else ord('a')
            shifted = chr((ord(char) - ascii_base + shift) % 26 + ascii_base)
            result += shifted
        else:
            result += char
    return result

def caesar_decrypt(text, shift):
    return caesar_encrypt(text, -shift)
